# Supervisor Issue Triage Prototype

This is a personal learning project made with React, TypeScript, Vite, and Fluent UI. It uses invented incidents and a simulated AI summary. It is not connected to real research, company systems, an AI service, or the official CCA toolkit.

## Start the prototype

```powershell
npm install
npm run dev
```

Open the URL printed in the terminal, normally `http://localhost:5173/`.

## Try it

1. Search or filter the incident list.
2. Select an incident.
3. Generate a simulated AI incident summary.
4. Inspect its dummy sources and leave feedback.
5. Assign or resolve the incident.

Reloading the page resets all changes.
